New features and fixes since v0.2.1:

- Glowing lines along the pane borders show which sessions are messaging each other and in which direction, with a dashed line and label while one is waiting for a reply
- Each conversation between sessions gets its own pane corner, so the lines rarely overlap
- "+ General session" button in the sidebar starts Claude without picking a project
- Dragging to select text now highlights as you drag, instead of only after letting go of the mouse button

Download the zip, extract it and run claude-terminal.exe.
