New features and fixes since v0.1.1:

- Live view of a running game or editor inside a session's pane
- Running shell commands show how long they have taken and roughly when they will finish
- Project log window: a project's work log grouped by hour, day and week, with charts and shared notes
- Nightly Build window (right-click a project) that sets up scheduled Windows builds: package the game, compile the editor, or run build.bat
- Project settings window (right-click a project) with a RAM section: let the shared RAM checker learn how much this project's heavy jobs need, or set a fixed amount, and see the current estimates
- Screenshot panel: delete all hidden screenshots, and right-click a screenshot to jump to its session or show the file
- The top bar keeps every open session reachable: sessions that don't fit go behind a "..." button
- Long session names on the top bar are shortened, with the full name on hover
- Background commands keep their progress bar with newer Claude Code versions
- Double-clicking an archived session restores it
- Clear message when the C++ compiler is missing when building from source
- The code is split into smaller files, with no change in behaviour

Download the zip, extract it and run claude-terminal.exe.
